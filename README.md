The portfolio includes practical exercises and final reports related to SQL, relational databases, data modeling, NoSQL, Python, Pandas, Power BI, data visualization, REST APIs and business-oriented data analysis.

## Projects by Sprint

### Sprint 02 - SQL Fundamentals
Introduction to relational databases and SQL fundamentals, including basic queries, table inspection and database exploration.

### Sprint 03 - SQL Tables, Indexes and Views
Practice with table management, indexes, views and SQL structures used to organize and optimize data access.

### Sprint 04 - SQL Data Modeling
Design and development of a relational data model, including tables, relationships, keys, data granularity and database structure.

### Sprint 05 - NoSQL and MongoDB
Introduction to non-relational databases, MongoDB concepts and comparison between relational and non-relational database models.

### Sprint 07 - Power BI KPIs and DAX
Introduction to Power BI, business indicators, KPIs, transformations and basic DAX measures for analytical reporting.

### Sprint 08 - Power BI Reports and Dashboards
Creation of business reports, dashboards and visualizations focused on communicating insights clearly and effectively.

### Sprint 09 - Python Fundamentals
Practice with Python basics, data structures, control flow, functions and reusable code for data analysis.

### Sprint 10 - Pandas Data Analysis
Data cleaning, transformation, grouping, pivot tables, calculated columns and exploratory analysis using Pandas.

### Sprint 11 - Data Visualization and Power BI
Integration of Python, MySQL and Power BI to create analytical visualizations and business-oriented dashboards.

### Sprint 12 - REST API Data Consumption
Consumption of data from REST APIs, processing JSON responses and transforming external data into Pandas DataFrames.
