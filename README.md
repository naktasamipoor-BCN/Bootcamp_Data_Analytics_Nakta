## Selected Projects

### Sustainable E-commerce Route Planning - Sprint 13 Final Project

Built a complete data analysis project to compare delivery route options by balancing time, cost, traffic, reliability and estimated CO₂ indicators.

The project uses multiple datasets related to e-commerce route planning, carbon footprint, transportation tracking and Barcelona traffic context. Since the datasets do not share a common transaction ID, the analysis is organized into clear modules. A simplified Delivery Option Score was created as an educational decision-support model to rank route options in a transparent and explainable way.

The final deliverables include a notebook, CSV outputs, visual reports, presentation files and a deployed Streamlit dashboard.

**Live dashboard:**
https://sustainable-ecommerce-route-planning.streamlit.app/

**Main skills:** Python, Pandas, Streamlit, data cleaning, KPI calculation, EDA, visualization, sustainability metrics, route scoring, dashboard deployment.

### Python & Pandas Data Analysis

Cleaned and transformed datasets using Pandas, created calculated columns, grouped data and prepared analytical outputs.

**Main skills:** Python, Pandas, data cleaning, transformation, grouping, exploratory analysis.

**Main skills:** REST API, HTTP requests, JSON, Pandas, data extraction, external data sources.
