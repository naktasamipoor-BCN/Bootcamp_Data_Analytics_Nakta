# Sprint 09 - Python Fundamentals

This project is part of my Data Analytics bootcamp portfolio at IT Academy / Barcelona Activa.

The main goal of this sprint was to practice Python fundamentals through reusable functions, data structures, loops, validations, text file processing and simple automation.

The exercises cover basic Python logic as well as practical tasks such as reading `.txt` files, counting word frequencies, working with dictionaries and preparing structured outputs for analysis.

---

## Main Objectives

- Practice Python fundamentals for data analysis
- Create reusable functions
- Use conditional logic and loops
- Work with lists, tuples and dictionaries
- Validate user inputs and handle invalid values
- Read and process `.txt` files
- Clean text data before analysis
- Count word frequencies
- Work with nested dictionaries
- Convert structured results into pandas DataFrames
- Build clear and reusable code

## Exercises Included

### Level 1

#### Exercise 1 - BMI Calculator

A function to calculate Body Mass Index using weight and height.

The function validates the input values, checks whether they are numeric and reasonable, calculates the BMI and classifies the result into a category.

**Skills practiced:**

- Function creation
- Numeric validation
- Conditional logic
- Dictionary output
- Interactive input

---

#### Exercise 2 - Temperature Converter

A function to convert temperatures between Celsius, Fahrenheit and Kelvin.

The function uses Celsius as an intermediate unit and returns all conversions in a structured dictionary.

**Skills practiced:**

- Function logic
- Unit conversion
- Input validation
- Dictionary results
- Interactive input

---

#### Exercise 3 - Word Counter

A function to count how many times each word appears in a text.

The text is cleaned by converting it to lowercase and removing punctuation before counting the words.

**Skills practiced:**

- String cleaning
- Regular expressions
- Word frequency counting
- `Counter`
- Basic text analysis

---

#### Exercise 4 - Reverse Dictionary

A function to reverse the keys and values of a dictionary.

If duplicate values exist, the function keeps all related original keys in a list to avoid losing information.

**Skills practiced:**

- Dictionary manipulation
- Handling duplicate values
- Structured output
- Data validation

---

### Level 2

#### Exercise 1 - Word Counter from TXT Files

A function to read external `.txt` files, clean the text, count word frequencies and organize the results.

The exercise uses text files included in the project folder.

**Skills practiced:**

- Reading external TXT files
- Text cleaning
- Word frequency analysis
- Nested dictionaries
- Sorting words alphabetically
- Creating structured outputs

---

#### Exercise 2 - Data Type Conversion

A function to analyze a list containing different data types and separate values that can be converted to float from those that cannot.

The function also handles nested lists and tuples by flattening them before conversion.

**Skills practiced:**

- Recursive functions
- Flattening nested structures
- Type conversion
- Error handling
- Data validation
