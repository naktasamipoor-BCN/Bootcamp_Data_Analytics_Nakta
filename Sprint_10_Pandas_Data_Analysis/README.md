# Sprint 10 - Pandas Data Analysis

This project is part of my Data Analytics bootcamp portfolio at IT Academy / Barcelona Activa.

The main goal of this sprint was to practice data analysis with Python and Pandas by importing, cleaning, transforming and analyzing structured datasets.

The project focuses on preparing raw data for analysis, creating new columns, working with indexes, applying transformations, generating summaries and exporting analytical results.

---

## Main Objectives

- Import and inspect datasets with Pandas
- Clean and transform structured data
- Work with indexes and column renaming
- Create calculated columns
- Apply conditional transformations
- Group and aggregate data
- Create pivot tables
- Analyze descriptive statistics
- Export processed results
- Prepare data for visualization and business reporting
